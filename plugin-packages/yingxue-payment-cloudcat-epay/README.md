# 云猫码支付

映雪内置的 `yingce.payment/v1` 支付插件，通过云猫码易支付兼容接口创建充值订单并验签处理异步通知。

插件固定使用官方 HTTPS 网关，商户密钥只保存在后端加密配置中。查单使用已实测的 POST 表单合同，密钥仅放请求体并禁止重定向。关单和账单下载仍明确返回不支持，未确认平台关单前不会声称支付已取消。

收银台在站内显示二维码，使用所选支付宝或微信 App 扫码支付。二维码保留官方订单收银台链接原值，不在桌面浏览器跳转，不解析或替换成静态收款码。

用户端展示支付宝、微信支付，不展示收单服务商名称。后台分别配置支付宝经营码、微信打赏码、个人微信码的通道 ID；宿主根据套餐金额生成支付方式与通道快照，插件将其作为 `type` 和 `channel_id` 纳入签名。历史订单继续使用原配置，不重新选路。
