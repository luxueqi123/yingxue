# Kling 2.5 Turbo Video

独立的影策v2声明式Provider，只使用`kling-v2-5-turbo`原版本。安装不创建或修改渠道。

接入架构：[影策插件架构与接入说明](https://my.feishu.cn/docx/HPePdtuGoosbKhxF950crh5fnpb)第7、8、12、13章。
上游合同：[可灵2.5专页](https://klingai.com/document-api/api/video/2-5-turbo)及[页面链接的旧版接口](https://klingai.com/document-api/api/video/2-5-turbo/image-to-video/legacy)。

配置已授权渠道的API Key，显式选择2.5模型。支持一个首帧，或pro档位的首尾帧；5/10秒、std 720p或pro 1080p。原提示词、图像字节和角色保持。当前未宣称真实上游生成或生产验收。
