## 主题

主题界面的主色依据人物图片中的雾白、银灰和墨色，浅冷蓝仅作为交互强调。已移除先前误用的竹绿页面、侧栏、选中态及控件底色，后台面板使用同一灰阶。人物背景继续保持低对比、半透明和柔焦羽化，正文及控件不模糊，输入框鼠标跟随高光保留。此项调整主题显示样式，不覆盖已保存的画布数据或其它皮肤。

皮肤 ID 为 `luxueqi-tianya`，提供「月白」「竹夜」两种模式。每种模式完整定义 50 项颜色 token，共用 16 项数值参数及阴影样式；主按钮有独立渐变、悬停和按下状态。主题包补齐首页、LTV 工作区语义变量、后台、登录控件、画布节点、连接线、时间轴、标题字体、助手头像、积分标记、空状态和 404 图形。业务入口、首页分区、页面文案及已配置的登录影片继续由原有功能负责。

主题由 `web/src/themes/luxueqi-tianya/index.ts` 登记，样式限于当前皮肤。颜色数据与后端共用 `backend/internal/app/appearance_theme_packs.json`。外观设置版本 13 对已有版本 12 的站点只补入这一套主题，保留当前选择，不重新加入管理员已经删除的另外两套主题；皮肤库满 16 套时不挤占已有主题。切换主题时沿用现有画布预设恢复机制，不修改已经保存的画布数据。

## 素材

主题静态资源只加工用户提供的竹林场景、动画画面和角色设定图三个文件，具体文件名、SHA-256 及来源见 `web/public/themes/luxueqi-tianya/sources.json`。返工助手的首帧以用户动画面部及服装设定为参考生成，四份动作原片及八段最终视频摘要记录在来源与制作回执中。输入原图保持，没有使用衍生游戏模型、截图、界面或道具资源。标题复用现有 Noto Serif SC 字体及原有许可证。

`scripts/build-luxueqi-theme.py --source <原素材目录> --skip-video` 重建静态主题。视频由实际生成原片另行审查、剪辑及打包，不以脚本重新生成人物动作；处理依赖 Pillow、NumPy、FFmpeg 与 FFprobe。不会把主题图片写入用户素材库。

## 助手接入合同

当前 Q 版助手沿用影策原生 `avatarType: bundle` 动画包，根目录包含 `avatar.json` 与八个独立 H.264 MP4，尺寸 834×1112、24fps、无音轨，共 30,564,385 字节。造型以陆雪琪本人的五官、服饰配饰为参考统一 Q 版化，表情放松。动作从 Seedance 2.0 的五份实际全身原片中选取完整起势和收势，另一份 2.5 原片保留作制作对照。没有使用静态贴图形变、倒放、插帧、循环叠化或强制首尾扭曲，也不是 Cubism 绑定模型。

| 真实 Agent 状态 | 动画片段 |
| --- | --- |
| 待命 | `idle` |
| 排队 | `sleep_loop` |
| 运行 | `working_loop` |
| 等待审批 | `think` |
| 完成 | `wave` |
| 异常 | `wipe_sweat` |
| 停止 | `lie_down` |
| 拒绝 | `rejected` |

片段文件名遵循原生映射，保留原始自然加减速、眨眼及衣发运动。形象高度由后台设置，支持 120–360px；动画包预览立即随输入值等比调整，保存后同步到各页面的悬浮助手。画布以外及窄屏不再固定封顶 120px，仅在超出可用视口时等比缩小。本次上线保留管理员现有名称和 360px 高度。动画沿用 `AgentAvatarVideo` 的绿幕抠像和暂停逻辑，并按实际显示尺寸及不超过两倍设备像素密度绘制，最长边 640px，不放大低分辨率原片；主题内的小头像由 `ThemePack.agentOrb` 提供。

## 安装

完整主题需发布本次前后端源码与对应静态目录；仅导入颜色不能替代完整主题发布。发布后，在「站点及外观 → 皮肤主题」选择「陆雪琪 · 天琊」并保存。旧服务端可在前端发布后使用 `web/scripts/export-luxueqi-theme.ts` 导出的原生皮肤库安装脚本。

助手在原生「Agent 动画包」入口上传 `luxueqi-assistant.zip`，检查八个状态的预览，将助手名称设为「陆雪琪」并保存。导入本身不等于启用，不覆盖内置形象文件。品牌名称、Logo、登录影片、模型渠道、权限及密钥无需修改。
