# 映雪会员：功能使用权与积分购买优惠

状态：按用户新方向重做的产品与实现合同。替代“会员主要包含大量月积分”的旧方案；具体月费、折扣及赠分数仍为建议，尚未修改生产套餐或开放购买。

## 产品定位

会员费购买电商Agent等软件使用权，以及积分购买优惠。积分另外按需购买，作为实际模型调用的消耗品。会员只送少量体验积分，不把月费包装成大额充值，不按每月几千至几万积分划分会员等级。

前期先做一档，用户与需求增长后再决定是否需要商家、团队或批量制作等分档。电商Agent能力、席位和效率确有差异后再分层，不先虚构三档内容。

## 首发建议

| 项目 | 功能会员建议 |
| --- | --- |
| 月费 | 暂以29元作为试算价，最终未确认 |
| 电商Agent | 开放商品分析、创意方向、文案助写与主图/海报/详情图制作流程 |
| 购买积分 | 同一积分商品的当前售价9折，获得的积分数量不变；10元商品可9元购买，不要求先大额充值 |
| 赠送积分 | 每个会员月100点，用于体验，随本期到账并标明到期日 |
| 模型使用 | 分析、文案、出图等产生的模型费用都按明示报价扣积分；功能使用权不包含无限生成 |
| 购买积分有效期 | 沿用已购积分合同；会员到期不追回或清空已购买的积分 |
| 年付 | 首发关闭，不用高年费换取低单价 |

普通用户继续使用基础创作及普通积分购买。未开会员可了解电商Agent能力；开通后进入完整流程。会员到期停止新Agent调用与新的购买优惠，已有项目、历史结果和合法资源继续可读、可下载；不能借会员到期锁住用户资产。任务进行期间到期的，已有授权任务按原合同完成。

赠分不是充值，不再自动从赠分计算推广佣金。会员费是否参与推广返佣单独配置和展示，不能因订单携带100点体验积分而隐式套用充值返佣。积分购买继续按现有合格邀请关系计返佣，实际规则须在购买前展示。

## 权限及计费边界

电商Agent当前只检查全站FeatureEcommerce开关，没有独立会员权益。需要增加服务端会员权限检查，而不只隐藏前端入口。

应在商品分析、推荐、文案助写、报价、生成及重试等新调用入口检查权益。在上游调用之前校验，不让未付费调用先产生费用。本人已有任务的读取、取消、历史画布与文件导出保留归属校验，不简单一刀切成会员到期403。

分析和文案助写当前有直接模型调用，尚未全部有独立扣费账单；生成有积分预扣，部分内部分析与规划成本也需梳理。新方案应将各阶段调用纳入清晰报价和账务，或设置明确的会员体验成本额度，不能让会员身份承载无限免费识图/助写。缓存命中不重复算作新的上游消费，失败或缓存不可用不能伪造成功。

现有模型全局倍率、分组倍率不能用来实现“购买积分打折”，因为它们改变的是消费价格。新增套餐权益应独立表达：电商Agent使用权、购买积分实付比例、小额周期赠分；保留版本快照。赠分可使用现有lot与到期、原路返还机制。

## 积分优惠合同

同一商品积分不变，会员实付价下降。服务端在创建支付订单时核验当时有效会员，固定原价、折后实付、优惠来源、套餐版本及积分数；收银台、币种兑换、支付回调验金额、对账和退款均以同一订单快照为准。

同一幂等键返回原订单，会员到期或套餐改价不改变已创建订单的金额；新订单按当前资格重新核算。优惠在服务端算，不能接受客户端提交折扣或金额。显示价格和实际收款需要同一路径，不能只给前端价格乘0.9。

首发折扣建议最低9折，并纳入当前阶梯赠分一起计算成本。若未来增加优惠券、首购、专享积分包或模型折扣，应重新计算最优惠组合，不能无界叠加。成本未明确的规格仍是核算缺口，不能因为改成购买优惠就认为成本风险消失。

## 利润拆分

会员收入与积分销售收入分开核算。

```text
会员贡献额 = 会员费 − 体验积分兑现成本 − 会员付费手续费 − 会员功能未单独收费的成本 − 服务运维分摊

积分销售贡献额 = 折后实收 − 所售积分实际模型成本 − 推广积分兑现成本 − 支付手续费 − 相关存储/出网等成本
```

不能把客户尚未消费的积分充值全额当利润，也不能把会员费附带100积分理解成会员单价29元买100积分。

试算仍按模型售价为成本2倍的已核对路线、1元100基础积分，故每点兑现模型成本为0.005元；支付手续费暂用0.6%，积分返佣按所售积分的10%且全部被使用估算。这些不是供应商账单核验或税后净利润，未知成本模型不能套用该保证。

29元月费、赠100点：体验积分预计成本0.50元，支付手续费预算0.174元，剩余**28.326元**用于承担未单独收费的Agent调用、服务运维和利润。该金额不是净利，功能调用纳入积分账务后才能确定真实贡献；赠分返佣需明确排除，会员费返佣另行核算。

会员价为同商品价格比较，不构成已经在生产生效的报价。会员可从小额购买获得优惠；不要求为了最低单价先购买年会员或预存数千元。

## 上线改造范围与当前状态

1. 后台套餐从大量积分包转为功能权益、积分购买折扣和少量赠分，前台不再以大额积分作主卖点。
2. 支付订单与商品列表共用会员价格核算，固化优惠快照并覆盖实际币种/验金额/对账，禁止展示和收款两种金额。
3. 电商Agent服务端权益、到期与历史资产访问，以及识图/助写/出图完整成本账务。
4. 区分会员赠分和充值返佣，会员费返佣另定义；小额赠分lot仍先到期先使用、失败原来源返还。
5. 权限和折扣准备好、月费与比例明确并能购买后，再切换电商Agent商业权限；避免全部套餐仍为草稿时先锁住现有用户。

本次完成方向修订、入口核查与预算复算，尚未实现上述新权益字段、会员购买折扣和Agent会员门禁。原生产三档仍为未上架草稿；没有改变用户现有使用权限、充值金额或余额。
