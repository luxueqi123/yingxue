- 33 款外部运镜与上游 `motion.list` 重复，未再次导入，也未新增运镜按钮。

- 来源中的固定 15 秒要求改为所选模型支持的时长；不覆盖受保护的分镜 JSON 合同。
- 去除来源平台的提示词防线、固定模型优先推荐和不存在的参考图承诺；纠正来源中文九宫格的 `3×9=9` 错误。
- 转绘分析需要用户提供有权使用的参考素材及支持读取的模型。技能有完整文字不等于当前账号已接好所有媒体模型。
- 逐项生成质量、真实短信/邮箱送达、外部 OSS/CDN 和收费模型链路仍需要相应渠道验收。

## 新增的小工作流

画布云端 Agent 已有完成的助手回复时，显示「提炼为技能」。入口先预填当前会话的可见文字，排除工具正文、推理与流式未完成消息；长会话只保留最近内容并提示截取。

复用现有技能编辑抽屉与 `skill_draft` 任务：用户检查/编辑材料后点击「生成草稿」，才会调用当前文本模型。材料会进入任务记录并按现有渠道规则计费，需先移除隐私。草稿仍需用户编辑和保存；会话来源技能默认私有。

「停止等待」只停止当前页面监听，不表示服务端取消或停止计费；应到任务中心核对或取消任务。停止后再次生成需要确认，防止误认为无费用重试。关闭或切换账号时旧请求不能回填新编辑器或新账号的技能列表。

## 升级保护

合并上游静态分包保留机制，同时保留映雪技能媒体与案例媒体只读挂载；Nginx 缺失 JS 返回真实 404，不回退成 HTML。

上游新增验证/短信模型仅写在初始建表路径，旧库存在升级缺口。本轮补增量迁移 v36；生产发布前必须在 PostgreSQL 副本上验证，并确认业务表原有行不变。不得更改已部署迁移的 checksum。
