# 界面语言

界面语言使用随应用发布的本地资源。当前提供简体中文、繁體中文（香港）、繁體中文（台灣）、English、日本語、한국어、Español 和 Português (Brasil)；工作台顶部、登录页和展示页提供选择器，画布内从左上菜单的“界面语言”切换。

首次访问按访问 IP 所在国家或地区匹配现有语言：中国大陆、香港/澳门、台湾、日本、韩国分别使用对应语言，主要英语地区使用英语，西班牙语地区使用西语，巴西及葡萄牙使用巴西葡语。未覆盖地区优先使用浏览器支持语言；仍无匹配时使用简体中文。这是语言默认值，不改变账号、内容或地区权限。

识别使用本站同源 Cloudflare `/cdn-cgi/trace`，只读取国家/地区码，不记录或保存 IP、原始响应，也不新增第三方 IP 查询服务。识别等待上限为1.2秒；失败、超时或非 Cloudflare 部署均回退浏览器语言。非中文资源按需加载，成功后在当前页面缓存；语言包加载失败时仍可进入中文界面并重试。

浏览器仅保存语言及 `automatic`/`manual` 选择方式。自动模式在下次访问时重新识别；手动选择后始终优先使用该选择，并跳过 IP 查询。旧版已保存的语言按手动偏好保留，损坏或非法偏好重新自动识别。初始化在存储就绪后提交，HTML 的 `lang` 和 Ant Design 控件语言跟随同一状态；手动切换不重新挂载页面，不修改输入内容或工程数据。

## 本地资源

`web/src/lib/interface-locale.ts` 是语言注册、加载、缓存、回退和插值的唯一入口。八份资源在 `web/src/lib/locales/`，文件名与注册的语言代码一致；键集合与占位符由资源专项校验。本地群友站的语言选择和可读取资源为参考，缺失词条使用随应用发布的静态补译。缺少的键按中文回退，`{name}`、`{count}` 等插值只替换一次，不递归解释用户值中的占位符。回退不代表该页面已完成翻译验收。

组件使用 `useInterfaceTranslation()` 获取当前 `t`，状态由 `useInterfaceLocaleStore` 持有。组件内展示文案在渲染时翻译，不能在模块初始化时缓存翻译后的字符串。增加语种时应同时提供本地资源、注册与选项、语言状态对应关系及 Ant Design 语言，并通过键集合和占位符校验；没有资源的语种不开放选择。

## 文案边界

翻译对象是导航、按钮、弹窗、空态、加载状态及其它界面说明。内置分类、状态、规格的显示标签跟随界面语言，内部枚举与模型参数保持不变。工程名称、案例标题、来源资产的原始分类、自定义分类、节点名称、提示词、正文、字幕、模型名称、作者、昵称和媒体内容保持原文。管理员配置的品牌描述属于配置内容，也保持原文。Agent 默认外观文案按精确默认值本地化，管理员自定义文案保持原样。

不使用 DOM 全文替换或运行时机器翻译，不向外部翻译服务发送用户内容。后端和上游返回的原始错误不按文字猜译。主入口、创作页、画布已有本地化界面及 Agent 外壳接入本地语言包；其它模块的硬编码文案和完整覆盖程度仍以专项验收记录为准，语言切换能力不代表所有业务页面已完成翻译。

## 验证入口

资源键与占位符、失败重试和缓存使用 `web/test/interface-locale-loading.test.ts`；持久化与失败状态使用 `interface-locale-store.test.ts`、`interface-locale-hydration.test.ts`，后者包括首次初始化的独立进程回归。`chunk-recovery-locale.test.ts` 验证语言包失败由选择器处理并保留输入，同时保留路由代码加载失败时原有的页面恢复能力。组件本地化专项继续使用已有 `*-locale.test.tsx`。测试涉及模块替换时使用现有隔离运行器，避免不同文件的 store mock 相互污染。

`interface-locale-auto.test.ts` 使用隔离启动进程验证八种地区默认、旧偏好优先、自动模式重新识别、较晚响应不覆盖手动选择、浏览器回退与超时释放。实际 IP 识别与受控地区的浏览器验证在发布回执中分别记录；不把受控地区响应当作全球不同出口的实测。

浏览器需验证刷新、跨页、输入和选区保持、失败恢复、画布菜单、明暗与小屏显示。部署和整站覆盖的实际结果另记在待验清单，不由类型或构建成功推定。
