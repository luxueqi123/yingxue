# 功能清单

## 在线支付充值

积分中心 `/wallet` 支持按后台套餐创建在线支付订单，并展示支付二维码或跳转收银台。当前接入易支付兼容协议，可由管理员在“积分运营 → 在线支付”中配置平台地址、下单接口路径、商户 ID、商户密钥、本站公网地址和开放的支付方式。

- 商户密钥加密保存且不在管理端回显，留空保存会保留现有密钥。
- 支付订单固化套餐、金额、积分和商户凭据快照，避免配置变化影响已创建订单。
- 同时兼容易支付返回二维码内容、二维码图片、URL Scheme 和收银台链接。
- 异步回调验签，并校验金额、支付方式及上游交易号后幂等入账；重复回调不会重复增加积分。
- 前台保留最近充值订单，可重新打开待支付订单；确认服务端已入账后自动刷新余额。
- 套餐卡始终可点击：支付可用时进入付款方式选择和下单，未配置、加载中或读取失败时展示对应状态并支持重新检测，不再留下无响应的占位卡片。
- 兑换码充值保留为独立入口；页面不再展示“充值请联系本人”的个人联系方式。

相关实现：`backend/internal/service/payments.go`、`backend/internal/repository/payments.go`、`web/src/pages/wallet/index.tsx` 和 `web/src/pages/admin/components/credit-operations-panel.tsx`。

## 提示词库

`/prompts` 是映雪自有维护的提示词中心，已导入技能中心完整公开提示词资料（去重后 14,103 条），另有 13 条映雪自制示例，共 14,116 条；其中 100 条会作为编辑精选稳定排在前列。提示词正文、元数据、分类兜底封面和来源说明保存在后端数据库中；卡片与详情优先显示每条记录对应的原始案例图，原始图不可用时才退回分类兜底封面，不依赖上游仓库的浏览器直连或 IndexedDB 缓存。

### 当前能力

- 精选案例卡片：封面、生成模式、分类、标签、作者、使用次数和适用模型建议。
- 标题、正文、标签、分类和模式筛选；支持精选、我的、我创建的、收藏和最近使用范围。
- 详情抽屉查看完整正文、来源/许可说明，并支持复制。
- 一键带入创作页；图片、视频和文本提示词会自动切换对应模式。音频提示词通过“插入画布”进入音频生成节点，避免把创作页暂不支持的模式误导成文本。
- 一键插入画布：图片/视频/音频生成提示词创建配置节点，文本提示词创建文本节点，打开后可继续编辑或生成。
- 案例封面可保存到当前账号的素材库；保存时优先导入该条提示词的原始案例图，无法导入时才使用分类兜底封面。用户可以创建、编辑、删除自己的提示词，并选择公开或仅自己可见。
- 收藏和使用记录按用户隔离；内置精选内容由映雪服务端幂等同步，公开/私有提示词的权限由服务端校验。
- 默认“最受欢迎”排序会把 100 条编辑精选稳定放在前排；其余长尾内容仍可通过关键词、原始资料类别标签和分类筛选检索。

完整资料来自 YouMind 公开社区整理，详情保留来源和许可提示；示例图仅作为参考，商业发布前应按来源页面核对原作者授权。上游开源项目仅用于学习功能设计。

### 相关实现

- `backend/internal/model/models_prompts.go`、`backend/internal/repository/prompts.go`、`backend/internal/service/prompts.go`：数据、权限和运营字段。
- `backend/internal/handler/prompts.go`：提示词列表、详情、创建、收藏和使用 API。
- `web/src/pages/prompts/index.tsx`、`web/src/services/api/prompts.ts`：提示词中心和一键带入入口。

## 素材库

`/assets` 同时提供账号私有素材和映雪内置素材两类内容。个人素材继续按账号隔离、可编辑、导出和删除；“映雪内置”展示随站点静态发布的 18 张风格参考图，不占用用户的素材存储额度，也不会伪装成用户自己上传的资产。

- 可在“全部素材 / 我的素材 / 映雪内置”之间切换，并继续按类型、业务分类和关键词筛选。
- 内置素材支持查看档案和“保存到我的素材”；保存后才进入该账号的可编辑素材记录与同步流程。
- 内置条目明确标为“站内内置风格参考”，用于创作参考，不作为独立商用图库素材包重新分发。

相关实现：`web/src/lib/yingxue-included-assets.ts` 提供目录元数据，`web/src/pages/assets/index.tsx` 负责浏览、筛选与保存入口。

## 技能库展示案例

技能广场中的内置技能使用自托管案例媒体。列表卡片显示首张案例封面，含视频的技能带有视频标识；详情抽屉支持图片浏览、视频封面、播放控制和媒体加载失败提示。

生产部署通过 `CANVAS_SKILL_MEDIA_PATH` 将宿主机数据盘目录只读挂载为 `/skill-media/`，图片和视频不依赖第三方临时签名链接，也不写入 Web 容器可写层。
## 邮箱找回密码

登录页在密码字段标题行提供“忘记密码？”入口。已配置账户邮件服务时，本地密码账号可以通过绑定邮箱获取 6 位验证码，并在 10 分钟内设置新密码；发送接口对存在和不存在的邮箱返回相同结果，避免公开账号状态。

密码更新、验证码消费和该账号全部旧登录会话撤销在同一个数据库事务内完成。验证码按注册与密码重置用途隔离，不能跨流程复用；Linux.do 单点登录账号继续通过原身份提供方登录，不会由找回流程隐式创建本地密码。

### 相关实现

- `web/src/pages/auth/login.tsx`、`web/src/pages/auth/forgot-password.tsx`：登录入口与两阶段邮箱验证界面。
- `backend/internal/service/password_reset.go`：发送策略、验证码校验和密码重置业务边界。
- `backend/internal/repository/repository.go`：密码更新、验证码消费和登录会话撤销事务。

## AI 提示词优化器

提示词优化器是一个内置 AI 能力插件，用于把模糊的生图或生视频想法整理成可以直接使用的提示词。它复用宿主已经配置的文本模型和渠道，不在浏览器中保存或拼接第三方密钥。

### 使用入口

- 创作页 `/create` 的提示词输入框中，点击“优化”。
- 画布中的图片或视频节点提示词编辑器中，点击“优化”。

面板使用紧凑的聊天式交互，跟随当前输入框定位，支持拖动、边缘调整尺寸和窗口尺寸变化。打开与关闭不使用延迟动效，避免遮挡画布或让用户误以为请求卡住。

### 优化方式

| 方式 | 用途 |
| --- | --- |
| 扩展想法 | 从模糊想法补齐主体、场景、构图、光线、镜头等可执行细节。 |
| 精修已有提示词 | 尽量保留原意，只修正表达并补充必要细节。 |
| 强化风格 | 保留主体和动作，强化色彩、材质、光影与指定风格。 |
| 适配模型 | 按当前生成模型和协议调整提示词结构，避免使用未确认的参数语法。 |
| 结合参考 | 使用已连接的图片或文本补充外观、一致性、构图和关联关系。 |

面板底部可以单独选择优化所使用的文本模型；目标生成模型仍取当前图片或视频生成配置。两者职责不同：前者负责整理提示词，后者负责最终生成内容。

### 结果与安全边界

- 优化结果以结构化内容返回，包含正向提示词、规避项、修改说明、假设和可选备选版本。
- 结果可以继续编辑；只有点击“采用”才会回填当前输入框，并自动关闭面板。
- 请求支持流式反馈、取消和错误提示，不会在优化失败时覆盖原提示词。
- 参考素材只提交当前已连接且符合类型的内容；插件不自行访问素材库或后端密钥。

### 相关实现

- `web/src/lib/plugins/builtin/prompt-optimizer.ts`：插件清单、优化方式和模型适配策略。
- `web/src/components/canvas/canvas-prompt-optimizer-drawer.tsx`：聊天面板、拖动缩放和结果采用交互。
- `web/src/services/plugin-host.ts`：将插件文本请求接入宿主现有模型渠道。
- `web/src/pages/create/index.tsx`、`web/src/components/canvas/canvas-node-prompt-panel.tsx`：两个入口的接入。

## 用户诊断包导出

设置页的“问题诊断”入口和任务失败快捷入口支持导出脱敏诊断包，帮助普通用户提交问题时保留足够的排障上下文。

### 当前能力

- 浏览器内存中保留最近的全局错误、未处理 Promise、API 请求和任务创建事件。
- 后端按当前登录用户、时间范围、任务或项目聚合 `Task`、`TaskLog` 和 `ApiCallLog`。
- 下载前显示数据量预览，并生成包含清单、运行时信息和 JSONL 日志的 ZIP。
- 默认排除提示词、任务输入、API Key、Cookie、上游请求/响应体和 URL 查询参数。

### 使用入口

- 设置页：`/settings?section=diagnostics`。
- 失败任务详情中的“导出诊断包”按钮会自动带入任务和项目范围。

相关设计和接口边界见[用户诊断包设计](../../../design/user-diagnostic-bundle.mdx)。

## 自由空白画布起点

新建且没有节点的自由画布会显示“从哪里开始”引导。除短剧流水线和 Agent 生成外，用户可以选择“自由空白画布”，在不预设工作流的情况下开始创作。

进入自由空白画布后，画布中央保留一个带加号的起始框。点击加号会打开与底部工具栏相同的添加菜单，可新建文本、绘图、分镜、背板、文件夹、图片、视频、音频和工作流，也可上传文件或打开素材库。插件提供的节点继续由同一命令注册表控制，不维护第二份素材类型清单。

自由起点选择按画布持久化；画布仍为空时刷新页面不会重新回到起始引导。中央起始框只负责提供入口，不创建占位节点。

### 相关实现

- `web/src/components/canvas/canvas-short-drama-entry.tsx`：起始引导、自由空白起始框和中央加号。
- `web/src/components/canvas/use-canvas-create-commands.ts`：工具栏与空白起点共用的添加命令解析。
- `web/src/lib/canvas/canvas-starter.ts`：空画布起点状态决策。
- `web/src/stores/canvas/use-canvas-store.ts`：按画布保存自由起点选择。

## 画布外观

底部工具栏的“画布外观”面板支持浅色、深色、自定义三种主题，以及点阵、线稿、空白三种网格。浅色画布使用比白色节点更沉的中性雾灰背景，深色画布使用比原深色节点更亮的中性灰背景，让画布底层与内容表面保持稳定区分，同时避免蓝灰背景与黑色工具浮层产生色温割裂。

自定义主题会继承用户进入前的浅色或深色基础界面，并允许在“浅色界面”和“深色界面”之间切换。界面样式复用原项目整套节点、工具浮层、文字、边框和交互状态，不开放这些元素的任意改色；切换界面样式不会覆盖已经选择的画布背景和网格颜色。

自定义主题还允许调整画布背景色、背景明亮度、网格颜色和网格强度。颜色输入支持三位或六位 HEX，可带或不带 `#`；形成合法色码后实时写入当前画布，编辑过程中不会被父级状态覆盖，关闭外观面板也不会撤销。选择新的画布背景色时明亮度自动归零，确保画布首先精确显示输入色；之后仍可沿 OKLCH 亮度轴单独调整。不提供背景透明度，避免画布底色与底层颜色混合后产生偏色。“网格强度”使用 `0%` 最淡、`100%` 最明显的方向，避免“透明度”命名歧义。

自定义外观可以应用到当前画布，也可以保存为当前浏览器、当前账号 scope 下的新建画布默认值。当前画布外观沿用画布项目的既有持久化和同步流程；浏览器默认值不跨设备同步。

### 相关实现

- `web/src/lib/canvas-theme.ts`：浅色、深色画布固定背景与原有节点、浮层 token。
- `web/src/lib/canvas/canvas-appearance.ts`：自定义外观归一化、解析和本机账号默认值。
- `web/src/components/canvas/canvas-toolbar.tsx`：画布外观面板入口。
- `web/src/components/canvas/canvas-appearance-controls.tsx`：主题、颜色、明亮度和网格控件。
- `web/src/components/canvas/infinite-canvas.tsx`：应用主题背景并保持网格渲染参数。

## 画布节点自动整理

画布底部的“自动整理节点”按钮用于快速改善节点排布，适合处理节点散落、间距不一致或流程方向不清晰的画布。

### 使用规则

- 选中了两个或以上节点时，只整理选中的可移动节点；没有选中节点时，整理所有顶层可移动节点。
- 候选节点存在连线时，横向保持从左到右的依赖层级，纵向按文本、图片、视频、音频分泳道；没有连线时，各媒体类型分别使用网格布局，不再把图片与视频混排。
- 锁定节点、容器节点和折叠批次中的隐藏子节点不会被移动。
- 节点位置变化会进入现有画布历史记录，可使用“撤销”恢复整理前的布局，并继续由画布生命周期自动保存。

### 相关实现

- `web/src/components/canvas/canvas-zoom-controls.tsx`：底部视图控制 Dock 与“自动整理节点”入口。
- `web/src/pages/canvas/use-canvas-node-operations.ts`：候选节点筛选、流程/网格布局选择和位置提交。
- `web/src/lib/canvas/canvas-layout.ts`：媒体泳道、拓扑流程、网格、行列排列和对齐算法。
