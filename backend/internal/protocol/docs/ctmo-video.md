# 靠谱 API 视频

## 接口与鉴权

{{OPERATIONS}}

本协议使用 JSON 请求体调用 `POST /v1/videos`，通过 `GET /v1/videos/{task_id}` 查询任务。渠道地址填写供应商 HTTPS 地址，凭据由服务端注入 `Authorization: Bearer`，不允许在浏览器链接中附带密钥。成功后使用同一供应商地址下的 `/v1/videos/{task_id}/content` 下载内容。不要把该协议与 OpenAI Videos 的 multipart 请求或 ArtBox 的 `/v1/video/generations` 混用。

## 模型与约束来源

管理员应使用各分组密钥读取实时 `/v1/models`，保存清晰度、时长、比例和图片、视频、音频参考上限。分组之间的同名或同清晰度模型不保证能力一致。目录可读取只证明目录响应正常，不能替代真实生成验收。价格字段中的按秒与按次必须分别配置，不依据名称推断单位；运营价格与上游成本分别保存，不向客户端公开上游模型别名。

神秘分组的 Seedance 2.0 使用音频参考时必须带图。900 按次模型只接受 10 秒与 15 秒，并要求提示词写明时长，适配器会追加所选秒数。稳定精选型号可能固定 15 秒，2.5 按次型号可能固定 30 秒，最终由渠道能力配置校验，不能向用户开放任意时长。

## 参数与字段映射

{{PARAMETERS}}

实际提交字段是 `model`、`prompt`、整数 `seconds`、`aspect_ratio` 和非空的 `images`、`videos`、`audios` URL 数组。分辨率由模型型号固定，当前不发送独立清晰度覆盖、音频生成开关和水印开关。参考素材必须在上游任务运行期间可访问，上传后的资源不能提前删除。未提供某类素材时省略对应字段。

## 任务状态与结果

创建成功保存供应商公开任务标识。`queued`、`in_progress` 与 `unknown` 均继续查询原任务，不能通过重复提交来处理未知状态。`failed` 停止轮询并向调用者报告失败；只有 `completed` 才开始下载结果。结果下载固定回到原供应商的鉴权内容路径，不信任任务响应中任意第三方结果地址。宿主将下载结果持久化为映雪资源，前台读取映雪资源，不接收供应商密钥。

## 官方资料与验证边界

供应商文档位于 https://video.ctmoai.com/docs ，稳定分组说明提供 JSON 请求示例。这里的“官方资料”指渠道自己发布的协议说明，不代表字节官方证明该渠道模型身份。文档示例的型号可能落后于当前目录，必须按当前密钥实时目录复核。协议单元测试验证请求字段、特殊时长、缺图拒绝和鉴权结果路径；是否有余额、生成成功率、实际分辨率与素材效果仍需真实任务验收。
